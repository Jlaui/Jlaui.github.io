Original Project – Project Two Dashboard

This project is an original application developed as part of my CS-340 course. It was created to showcase skills in Python, Jupyter Notebooks, and CRUD operations. The dashboard analyzes data related to animal shelter management, allowing for filtering and displaying of relevant statistics based on different categories.

Project Overview

The dashboard application allows filtering of animal shelter data, providing an interface for shelter workers to identify suitable candidates for rescue training based on various attributes like breed and age. The data is processed through a Jupyter Notebook and a Python CRUD module.

This project heavily takes into consideration how the users will be viewing the data and includes visualization components; a pie chart showing the distribution of dog breeds as well as a map showing the location.
