Capstone Project – CS-340 Dashboard Enhancement

This project is an enhanced version of a dashboard application originally created in CS-340 for Grazioso Salvare. It was developed as part of my CS-499 Computer Science Capstone to demonstrate growth in software engineering, algorithms, and database optimization.

Project Overview

The application processes animal shelter data to help identify suitable candidates for rescue training. It allows filtering by breed, age, and rescue type (disaster, water, and mountain rescue). The system displays results in both tabular and map-based formats.

Enhancements Completed

1. Software Engineering Improvements

The original Jupyter Notebook was converted into a structured Python application with improved separation of concerns and maintainable code design.

2. Algorithms and Data Structures

A custom ranking algorithm was implemented to evaluate animals based on multiple factors such as breed compatibility, age range, and behavioral traits. This allows for a better process of candidate selection.

3. Database Optimization

Performance improvements were made through indexing, aggregation pipelines, query optimization, pagination, and improved error handling for CRUD operations.
